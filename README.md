# Tracel

Tracel is a fast, modern logging and rollback system for Minecraft servers — built to handle everything from small servers to massive worlds.

Track changes, investigate what happened, and roll back exactly what you need, with high performance, safe concurrency, and reliable storage built in.

> [!WARNING]
> Tracel is in an early alpha: it's safe to use, but unexpected things can happen. Keep backups of your worlds.

<img alt="Tracel" src="https://github.com/user-attachments/assets/5076e62a-6320-4c6d-9c61-07c11d33516e" />

## What it does

- Logs blocks, entities, inventories, and item history
- Tracks item provenance across transfers, splits, crafting, and other events
- Lets you investigate exactly what happened and where
- Supports precise rollbacks with configurable scope
- Works on Paper, Folia, Purpur, and compatible forks
- Designed for high-performance servers and large worlds

Read more [in the wiki](https://github.com/arnodoelinger/tracel/wiki)!

## Get started

Install Tracel, run `/tracel inspect`, and start exploring your server's history. Need to revert something? Use `/tracel rollback`.

See the [wiki](https://github.com/arnodoelinger/tracel/wiki) for installation, commands, configuration, and more.
