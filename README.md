# Tracel

<img src="https://i.imgur.com/2WSWsnh.png" align="right" width="128">

A fast, modern block logging and rollback system for Minecraft servers — from small servers to the largest ones.

Built for modern Minecraft servers, with performance, concurrency, and reliable storage in mind.

> [!WARNING]
> Tracel is currently in active development and is in an early alpha stage.
>
> Use Tracel with **extreme caution** and always keep **backups** of your server and world data.

## Features

- **Powerful logging** — records world changes and makes it easy to find what happened
- **Fast rollbacks** — undo changes made by players or specific actions
- **Flexible lookup** — filter history by player, time, action, block, radius & more
- **Built for scale** — designed to handle really large amounts of history

## Get started

Install Tracel on your server and start playing. Tracel handles logging automatically.

Command: `/tracel <args...>`
